# AGENTS.md

Canonical guide for coding agents in this repository. `CLAUDE.md` imports it. `llms.txt` is the short index and `llms-full.txt` the full single-file reference.

## What this repo is

One checkout, two projects:

1. **The scaffolder (origin).** This is a fork of jeantimex/webgpu-foam, which publishes the npm initializer `create-vite-webgpu-project`. It is `bin/`, `template/`, the template demo in `src/` (everything except `src/foam/`), `index.html`, `tsconfig.json` and `test/`. Keep these as in the origin. The only fork changes are the `src/foam` copy filter in `bin/create-vite-webgpu-project.js` and `"!src/foam"` in `package.json` `files`.
2. **The Foam website.** It is a WebGPU learning site: `foam.html`, `src/foam/`, the Rust crate `dom-compiler/` and `public/`. The browser lays out invisible DOM, Rust (wasm) reads that layout into GPU instance buffers, pretext breaks text lines, and WebGPU draws every pane and glyph.

## Commands

```bash
npm install
npm run wasm            # wasm-pack build dom-compiler -> src/foam/lib/wasm (needs Rust + wasm-pack)
npm run dev             # Vite dev server; /, /about, /work serve foam.html
npx tsc --noEmit        # type-check src/ (demo + foam)
npm test                # scaffolder tests (node --test): generate, tsc and build projects
npm run test:wasm       # cargo test --manifest-path dom-compiler/Cargo.toml
npm run build           # tsc && vite build -> dist/ (index.html + foam.html)
npm run preview         # serve dist/ with the same route rewrite and cache headers
```

- Rerun `npm run wasm` after cloning and after every edit to `dom-compiler/`. `src/foam/lib/wasm/` is generated and git-ignored. Without it `tsc`, `dev` and `build` fail on `./wasm/dom_compiler.js`.
- A fresh clone has no `.env`. Create it with `VITE_SITE_ORIGIN=https://foam.example.com` (the value in use), or canonical and OG URLs start with `undefined`.

## Architecture

**Boot.** `boot.ts` calls `applyMeta(routeIndex())` at once, so the title, meta, `inert` routes and work chrome are right without WebGPU. After `load` and the first `paint` entry it runs `setTimeout(() => import('./main'))`. `main()` awaits `initDomCompiler()` + `document.fonts.ready`, then WebGPU, the grid mesh, `loadPhotos()` (one layer upload per task) and `createPipelines()`. It runs `warmText()` once per text element (one task each), then the `compileScenes()` generator (two yields per route). It adds a `ResizeObserver` on each route root that calls `recompile()`, sets up input and the router, calls `onRoute()` and starts the rAF loop. Errors are shown in `#message`.

**DOM to instances.** Each route root stays laid out but invisible (`[data-route] { opacity: 0; pointer-events: none }`). `compileRects(root, selector, colorProp)` calls the Rust `compile()`. For each match it emits 8 floats `[x, y, w, h, r, g, b, depth]`: document px (bounding rect + window scroll), the computed `colorProp` parsed from `rgb()`/`rgba()` (white when fully transparent or unparsable), and `depth` = number of `data-gl` ancestors. DOM hooks:

| Attribute | Meaning |
| --- | --- |
| `data-route="/path"` | One scene per `<main>`, in document order: 0 home, 1 about, 2 work. |
| `data-gl` | Box drawn with its `background-color`. A leaf gets a photo: its `data-photo`, else the next index (counter across routes, mod 13). A container (has `data-gl` descendants) keeps its flat colour. |
| `data-gl-image` | The work hero image (first match only). |
| `data-gl-text` | Text block drawn glyph by glyph in its `color`. `data-split="lines" \| "words" \| "chars"` (default `lines`). |
| `data-slide="i"` / `data-list` | Work text that belongs to slide `i` / to the list view. |
| `data-gl-frame` | Wire-only outline. Frames are `[data-gl-frame], [data-gl-text]:not([data-slide]):not([data-list])`. |

**One mesh.** `gridMesh()` is a 17x17-vertex grid (289 uvs, 1536 triangle indices, 128 outline indices, `uint16`). Every draw instances it: slot 0 = uv, slot 1 = per-instance data, slot 2 = one float per instance. `place()` in `scene.wgsl` maps doc px to world px (origin at viewport centre, y up) with `z = depth * 4`. The camera sits at `dist = h / 2 / tan(fov / 2)` with `fov = PI / 4`, so 1 world unit = 1 CSS px at z = 0. The pane swells toward the cursor: `exp(-d^2 / 220^2) * hover * lift`, up to 70 px. Wire draws are nudged toward the camera in clip space (`0.0005 * w`).

**Text.** `layoutText()` takes each text element's rect, uses pretext line breaks (`breakLines` at the rect width and computed line-height) and advances with canvas `measureText`. It emits one 13-float quad per non-space grapheme, sized to its ink box with 1 px padding. Each unique `font|grapheme` is shelf-packed once into a per-route 2048 px-wide atlas canvas, in device px and painted white. That canvas is copied to an `rgba8unorm` texture, and the shader tints it with the DOM colour. `vs_text` lifts text 3 depth layers (+12 px) above what it overlays.

**Split-text reveal.** Each text element has a gsap-tweened `time` (in a WeakMap, so it survives recompiles). The tween runs linearly from 0 to `maxDelay + 1.4` s (`GLYPH_SECONDS`). Each frame, glyph progress = `power3.out(clamp((time - delay) / 1.4))` is written to the slot-2 buffer. `vs_text` slides the glyph up from `lineBottom`, and `fs_text` discards below `lineBottom - 0.5` (the line mask). The stagger per unit is lines 0.1 s, words 0.04 s, chars 0.012 s. An `IntersectionObserver` plays a block the first time it is in view during a route visit. Hidden slides and the list text wait. During a route change the start is delayed by `max(0, 0.9 - p) * 1.6` s. `sink()` tweens `time` back to 0 over 0.5 s (`power2.in`).

**Routes and composite.** Routing uses the History API. `#nav` clicks call `pushState` (modifier or non-primary clicks stay native), and `popstate` also runs `onRoute()`. Each route renders to its own texture. All scene passes share one 4x MSAA colour target and one 4x `depth24plus` target (both `storeOp: 'discard'`) and resolve into `sceneTextures[scene]`. Only `from` and `to` render: one scene at rest, two during a reveal. `composite.wgsl` grows a circle from the centre (expo in-out, 1.6 s, 0.15 s with reduced motion). It shows `to` inside and `from` outside, with a refracting rim, RGB split and a highlight. The outgoing scene keeps its scroll (`sceneScroll`). A click mid-reveal restarts from whichever scene covers more of the screen (`from = to` when `p > 0.5`). Clear colours: about `[0.922, 0.902, 0.863]`, the others `[0.965, 0.957, 0.937]` (`--paper`).

**Work.** It has 13 slides, one per photo. `SLIDE_PHOTOS = [2, 6, 9, 11, 0, 4, 7, 12, 1, 3, 5, 8, 10]`, and the `slide` uniform is `[cur layer, next layer, k, list.v]`. A change takes 1.1 s: the next photo rises from the bottom while the current one drifts up and darkens, and a scrim darkens the bottom for the title. Arrow keys and the wheel step one slide. One wheel gesture = one slide: the lock releases after 220 ms of quiet, and `|deltaY| < 10` is ignored. The minimap buttons jump to a slide. The minimap shows five thumbnails and wraps around: `centerThumb(i)` sets each button's CSS `order` so the current one is always third. The Index button toggles the list view (`list.v` 0 to 1, 1.1 s `power3.inOut`). The hero image morphs from full screen into the current slide's row thumbnail, in whichever drawn copy is nearest the viewport centre. The list is drawn 3 times (`COPIES = [-1, 0, 1]`), one `listPeriod` apart, and scrolled modulo the period, so it repeats endlessly. Wheel and drag move the target, Up/Down move it by 200 px, and the frame loop eases toward it. A hovered row's thumbnail grows up to 6% and is lifted in depth. A click (pointer moved 6 px or less) or keyboard activation of `.row-btn` opens that slide. Escape closes the list. List boxes use `boxFade` (alpha = `list.v`), and list wires show only when `fade >= 0.5`.

**About.** The fan has 13 equal 180x240 fins (`FAN_CARDS`), one photo each, placed by the shader around the Y axis and tipped 0.45 rad toward the camera. It is still by default. Drag spins it at 0.006 rad/px. The velocity is smoothed and capped at ±8 rad/s, the wheel adds `deltaY * 0.004`, and friction is `exp(-dt * 1.8)`. The velocity drives the wave: the outer edge lags with `clamp(spinVel, ±4)` and a ripple runs down each fin.

**Scroll.** Only home scrolls the document. It uses Lenis, which the frame loop drives with `lenis.raf(now)`. Other routes set `overflow: hidden` and `lenis.stop()`. Work list scroll is separate state.

**View modes.** `#view` toggles `solid` (skip wire draws), `wire` (skip non-wire draws) and `both`.

## Contracts that must stay in sync

- **`STRIDE = 8`.** It is set in `dom-compiler/src/lib.rs` and `src/foam/lib/dom_compiler.ts`, and the layout is `[x, y, w, h, r, g, b, depth]`. `fan.ts`, `text_layout.ts`, `pipelines.ts` and `main.ts` index by it. `main.ts` writes `grown[o + 7]` (depth) and the hero `[x, y, w, h, 0, 0, 0, 1]`.
- **`TEXT_STRIDE = 13`** (`text_layout.ts`) = `STRIDE` + `[u0, v0, u1, v1]` at offset 8 + `lineBottom` at 12. `pipelines.ts` maps it as `@location(1)` offset 0, `@location(2)` offset 16, `@location(3)` offset 32 (`float32x4`), `@location(4)` offset 48 (`float32`). These must match the `vs_text` inputs.
- **`struct U` vs the uniform write.** `main.ts` writes a 32-float (128-byte) buffer per draw: 0-15 `viewProj`, 16-17 `viewport` (w, h CSS px), 18 `scroll`, 19 `spin`, 20 `count` (`FAN_CARDS`), 21 `wire`, 22 `ring`, 23 `spinVel`, 24-25 `mouse` (x, y + scroll), 26 `hover`, 27 `lift`, 28 `fade` (`list.v` for list draws, else 1), 29-31 `_p0.._p2`. Reorder both together. `mouse` is a `vec2f` at byte 96 and must stay 8-byte aligned, or WGSL inserts padding that shifts every later float.
- **Vertex slot 2** is one float per instance. For text it is `@location(5)` reveal progress 0..1, rewritten every frame. For boxes it is `@location(6)` photo layer, where -1 = flat colour. Every draw binds a slot-2 buffer: the hero image and frames get `noPhotos()` (all -1).
- **Bind group 0.** `scene.wgsl` declares 0 `U` uniform, 1 `atlas` texture_2d, 2 sampler, 3 `images` texture_2d_array, 4 `slide` vec4f uniform, 5 `aspects` read-only storage. `boxLayout` = 0, 2, 3, 4, 5 and is used by `image`, `boxSolid`, `boxWire`, `boxFade` and `textWire`. `textLayout` = 0, 1, 2 and is used by `textSolid`. The entries are `photoEntries` and the text extras in `main.ts`. `composite.wgsl` uses `layout: 'auto'`: 0 `C` uniform `[p, aspect, time, 0]`, 1 `fromTex`, 2 `toTex`, 3 sampler.
- **Fan fin size.** `fanCards()` writes 180x240 and `scene.wgsl` uses `FIN_W = 180.0`, `FIN_H = 240.0`. The rect only drives the photo crop.
- **Counts.** `PHOTOS` = 13 = `public/images/00..12.webp` = `FAN_CARDS`. `SLIDES = 13` = `.slide` blocks = `#work-list` rows = minimap buttons = `#counter` "01 / 13". `SLIDE_PHOTOS` matches the row `data-photo` values, `thumbs/` and the sr-only images. The `#minimap` width (5 x 48 px thumbs + 6 px gaps) is the five-thumbnail window `centerThumb` assumes.
- **Routes.** The `data-route` paths, `META` in `routes.ts`, `ROUTES` in `vite.config.ts`, `#nav` links and `public/sitemap.xml` list the same paths. Home must be index 0: `allowScroll()` is `to === 0`, and unknown paths fall back to 0.

## Conventions

- **Third-party packages are imported only in `src/foam/lib/*.ts`.** Website code imports those adapters. The wasm glue in `lib/wasm/` is imported only by `lib/dom_compiler.ts`. A new package gets its own thin adapter that exposes only what is used, and goes in `dependencies`. Check: `grep -rnE "^import .*'[^.][^']*';" src/foam --include=*.ts` lists only `src/foam/lib/` files.
- Folders by domain (`lib`, `renderer`, `router`, `scene`, `text`) and snake_case file names, like the origin (`orbit_control.ts`, `mesh_shader.ts`). WGSL lives in `.wgsl` files imported with `?raw`.
- Match each file's style: `src/` uses single quotes, `bin/` and `test/` use double quotes, 2-space indent, semicolons.
- Comments say why, in full sentences, above the code. `/** */` goes on exported functions; Rust uses `//!` and `///`. A deliberate shortcut gets a `ponytail:` comment that names its ceiling and the upgrade path (example: kerning in `text_layout.ts`). No commented-out code.
- Keep `src/foam` out of the scaffolder output. The `cp` filter in `bin/` skips it, package.json has `"!src/foam"`, and `npm test` fails if it leaks (its exact `readdir` assertions on generated `src/`).
- The site origin lives only in `.env` (`VITE_SITE_ORIGIN`). `foam.html` uses `%VITE_SITE_ORIGIN%` and `routes.ts` uses `import.meta.env.VITE_SITE_ORIGIN`. `robots.txt` and `sitemap.xml` are static copies.
- Do not change the template demo or the shared helpers in `src/math`, `src/utils` and `src/webgpu` for Foam's sake.

## Gotchas

- **The renderer loads only after a paint.** A tab that is never shown never boots it. In an automated or background browser, front the tab before you check the GPU output.
- **WGSL reserved words** include `from`, `target`, `filter`, `pass` and `type`. That is why the composite uses `fromTex`.
- **Sample textures before `discard`**, outside non-uniform branches: `textureSample` needs uniform control flow. `fs_text` samples first. `fs_solid` always samples and clamps the layer with `max(i.img, 0.0)`.
- **One uniform buffer per draw.** `queue.writeBuffer` calls land before the submitted passes run, so draws sharing one buffer would all see the last write.
- **MSAA.** `SAMPLES` must match `multisample.count` in every scene pipeline, the MSAA colour texture and the depth texture. The scene textures are single-sample resolve targets, and the composite pipeline is single-sample.
- **Depth.** Layer z = `depth * 4` px. Text adds 3 layers (+12 px). The work hero is written with depth 1, and hovered list thumbs add up to 1. Translucent pipelines (`boxFade`, `textSolid`) test depth but don't write it, with `less-equal`.
- **Layout must stay readable.** Never `display: none` a GL element or a route: its rect is 0. Use `opacity` or `visibility` (`#work-list` uses `visibility: hidden` outside list view).
- **Colours must compute to `rgb()`/`rgba()`**, as hex, named and `rgb()` values do. `parse_rgb` falls back to white for anything else, such as `oklch()` or `color()`.
- **`ResizeObserver` → `recompile()`** destroys every buffer in `owned` and rebuilds all draws synchronously. Anything allocated per compile must be pushed to `owned`.
- **Text metrics** use canvas advances without kerning, so lines can drift a few px from the DOM (see the `ponytail:` note).
- **Reduced motion** (`prefers-reduced-motion: reduce`): the route reveal takes 0.15 s, and text shows whole (`time` set to its full duration, no tween). Slide and list tweens take 0.01 s, the minimap scrolls with `'auto'`, and the cursor bulge is off (`hover` target 0). Keep these paths when you add motion.
- `inert` hides non-current routes from assistive tech. The `#work-list .row-btn` buttons stay real for keyboard use: `onclick` acts only when `e.detail === 0`, and pointer clicks are hit-tested in `main.ts`.
